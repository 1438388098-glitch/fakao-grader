# examples · 端到端示例（全程虚构）

本目录用一套**虚构**的题目/作答/报告，演示 fakao-grader 的完整链路。不包含任何真实法考真题——真实题库需要你用自己在题库平台的合法账号获取（见主 README「题库数据」）。

## 文件说明

| 文件 | 是什么 | 怎么来的 |
|------|--------|----------|
| `题库数据/刑法_raw.json` | 虚构示例题（1 题 2 问，带白/黑名单采分点） | 手工构造，字段结构与真实题库导出一致 |
| `作答/刑法-9001.md` | 虚构考生作答（故意含全对/等义/半分/冗余多种情形） | 手工构造 |
| `评分作业单-sample.md` | extract.js 对示例题的真实输出 | 由 `node scripts/extract.js 刑法 9001` 实际生成 |
| `批改报告-sample.md` | 判分报告形态示例 | 按 SKILL.md 模板撰写的演示样例（实际批改由 AI 运行时生成） |

## 自己跑一遍

```bash
# 1) 生成评分作业单（脚本输出，确定性可复现）
FAKAO_DATA_DIR="$(pwd)/examples/题库数据" node scripts/extract.js 刑法 9001

# 2) AI 批改：把本 skill 装进 ZCode / Claude Code 的技能目录后，在 examples/ 下对 agent 说：
#    "批改刑法 9001"（作答已在 作答/刑法-9001.md）
# 3) 对照 批改报告-sample.md 检查报告形态是否符合预期
```

## 这套示例能验证什么

- **作业单抽取**是确定性的：同一份 JSON 永远得到同一份作业单（tests/extract.test.js 里有端到端断言）
- **判分**是 AI 行为：宽严尺由 SKILL.md 的「校准样例」锚定，一致性评测协议见 [docs/eval.md](../docs/eval.md)
- 白名单/黑名单机制：示例作答里的口语表述（"白归自己"）经白名单给满分，展示「等义即给分」而非字面匹配
